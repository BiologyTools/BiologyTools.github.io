Detailed Description

Bridges BioLib's BioImage to the OmeZarrWriter, exporting a full 5D image as an OME-Zarr v3 dataset on local disk.

XY planes are written in tile-sized chunks so that even whole-slide images never require a full plane to be resident in memory at once. Peak allocation is bounded to a single tile (tileW × tileH × bytesPerSample).

RGB-interleaved buffers are deinterleaved into separate C planes so the output array shape is always (T, C, Z, Y, X) with scalar pixels.

All resolution levels present in b.Resolutions are written, producing a proper OME-NGFF multiscale pyramid.

static

Reads every label image stored under <zarrDir>/labels/ according to the OME-NGFF labels spec and converts each unique non-zero integer label ID into a ROI of type ROI.Type.Mask.

For each label sub-store the finest resolution level (index 0) is read one plane at a time (iterating Z, C, T from the parent b ). Every distinct pixel value > 0 in a plane becomes a separate ROI.Mask whose float array contains 1.0 wherever that label is present and 0.0 elsewhere.

The method is a no-op when no labels/ sub-directory exists, so it is safe to call unconditionally after opening any Zarr store.

Parameters
bThe parent BioImage that supplies physical-size calibration and ZCT extents.
zarrDirRoot path of the Zarr dataset on local disk (the directory that contains zarr.json).
Returns
List of ROI objects (one per unique label ID per plane). Returns an empty list when no labels are found.
