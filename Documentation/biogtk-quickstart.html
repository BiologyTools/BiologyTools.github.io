BioGTK quickstart

Open an OME-TIFF, draw a rectangular region of interest (ROI), and export the annotation to CSV.

Before you start

Download BioGTK and follow the installation instructions for your operating system.

  • Download BioGTK
  • .NET runtime, Windows, macOS, and Linux setup

Use your own .ome.tif or .ome.tiff file, or download single-channel.ome.tif from the Open Microscopy Environment sample collection.

1. Open the OME-TIFF

  1. Start BioGTK. In the BioGTK - Tabs View window, choose File → Open OME Images.
  2. Select the OME-TIFF and click OK. The image opens in a tab.

2. Draw a rectangle

  1. Click Tools on the menu bar to show the Tools window. Click the rectangle outline icon.
  2. In the image, hold the left mouse button and drag from the upper-left to the lower-right corner of the area you want to mark. Release the button to finish the rectangle.
  3. Choose ROI → ROI Manager to check that the annotation appears in the list.

3. Export the ROI to CSV

  1. With the image tab active, choose ROI → Export ROI's To CSV. BioGTK exports every annotation on the active image.
  2. Enter sample-rois.csv as the filename and click Ok.
  3. Open the CSV in a text editor or spreadsheet. If you drew one rectangle on the sample, the CSV should have one data row with Rectangle in the TYPE column and positive values for width (W) and height (H).

If the CSV contains only the header, select the image tab again and check ROI Manager for the rectangle before exporting.
