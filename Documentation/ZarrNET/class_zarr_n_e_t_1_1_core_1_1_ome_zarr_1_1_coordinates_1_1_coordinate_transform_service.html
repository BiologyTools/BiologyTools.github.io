Detailed Description

Converts between physical coordinate space (ROI in microns, etc.) and array index space (PixelRegion) using the coordinate transformations declared in OME-Zarr metadata.

OME-Zarr transform semantics map array index coordinates to physical coordinates. For an axis-aligned ROI, all corners are transformed and the returned pixel region is the smallest axis-aligned array-space enclosure.

Two levels of transforms are composed:

  1. Per-dataset transforms (on each DatasetMetadata)
  2. Top-level multiscale transforms (on MultiscaleMetadata itself)

Per-dataset transforms are applied first, then top-level transforms.
