Reads a tile from this resolution level using pixel coordinates.

Builds a full-rank PixelRegion from the XY tile parameters and the per-axis t/c/z indices, then delegates to ReadPixelRegionAsync. All coordinates are clamped to the array shape so edge tiles and zero-size requests never produce an invalid region.

AxisMetadata [] ZarrNET.Core.Nodes.ResolutionLevelNode.EffectiveAxes

Returns the axes for this resolution level. When the multiscale metadata does not declare axes (OME-Zarr spec v0.1/v0.2), standard axis names are inferred from the array rank using the conventional suffix of (t, c, z, y, x). This ensures callers never receive an empty axes array against a ranked array.
