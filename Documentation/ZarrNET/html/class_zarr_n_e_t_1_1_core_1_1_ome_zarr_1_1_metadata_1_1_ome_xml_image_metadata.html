Detailed Description

Metadata for a single Image element in OME-XML. Corresponds to one series in the bioformats2raw layout.

Carries the "rich" metadata that isn't available from the Zarr attributes alone: series name, channel names, physical sizes with units, instrument references, acquisition date, etc.
