Detailed Description

A bioformats2raw.layout wrapper group containing one or more image series. Analogous to a PlateNode — it's a container you navigate into.

The series are typically numbered sub-groups (0, 1, 2, ...). Series count and paths are resolved from three sources in priority order:

  1. Explicit "series" attribute in OME/.zattrs
  2. Image count from METADATA.ome.xml
  3. Bounded probing of consecutive numbered sub-groups
