Detailed Description

Thread-safe LRU cache for decoded chunk data, keyed by chunk path.

Designed to sit inside HttpZarrStore so that panning back over previously-fetched tiles hits memory instead of the network.

The eviction policy is approximate-LRU: on each access the entry is moved to the tail of a linked list, and when the byte budget is exceeded the head (oldest) entries are evicted. This avoids a full sort on every access while still giving good cache behaviour for spatial locality patterns (panning, zooming).

Concurrency: all public methods lock on a single object. This is fine because the lock is held only for O(1) pointer manipulation; the expensive work (HTTP fetch, decompression) happens outside.
