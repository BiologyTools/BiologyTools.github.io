Detailed Description

Provides a MemoryManager<T> implementation backed by a Java DirectBuffer. This is a bit backward because ultimatly Java owns the memory, and we just use this manager to obtain a Memory<byte> reference to it. Ideally, we would override DirectBuffer in the JDK to allocate from the runtime MemoryPool.
